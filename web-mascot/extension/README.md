# 浏览器扩展

构建：`npm run build:all`。加载 `dist-extension` 目录，或解压 `release` 中的 ZIP。
最低支持 Chrome / Edge 106，需要浏览器提供的 `sender.documentId`。

## 接力规则

- 一组全局桌宠跟随最近聚焦窗口的活动标签页，不为每个 URL 单独保存位置。
- 后台以 `tabId + documentId` 标识执行者，以 epoch 拒绝过期消息；交接消息定向发送到旧文档。
- 隐藏页面主动提交状态；新页面申请时也可以向旧文档拉取。有效提交先到达就完成交接，迟到响应不能覆盖新状态。
- 未初始化、完整组快照、主动清空分别表示为 `UNINITIALIZED`、`READY`、`CLEARED`。只有宠物身份集合与配置完全一致的组快照可以替换状态。
- 可见的旧窗口未确认停止时不强行授予新执行权。旧标签页已关闭、被丢弃、变为非活动，或同一标签页发生文档更换时，可以使用最近完整快照恢复；异常恢复可能回退到检查点。
- 普通动作保留准确的动作路径、冻结变量、动画帧及计时。双宠互动在跨文档恢复时结束，按所在表面选择合法待机或下落动作。
- 跨页恢复时，位置与冻结目标点共用工作区域映射，保留已建立的贴地、贴墙与贴顶关系；自由下落不标记为贴墙，恢复时应用当前动作的边界规则。
- 同一页面 resize 保留界内位置与冻结目标点；缩小窗口时收回越界锚点，不播放撞地动画；扩大窗口失去支撑后自由下落。
- 新建与复用都先准备整组状态和首帧图片，再显示、移除占位图并恢复模拟。失权时取消尚未完成的 XML 加载。

## 滚动与落地

- 保留 npm 版的文档滚动效果：实际页面位移合并为视口坐标系平移，空中继续换算，宠物在文档中的运动由自身速度和重力决定。地面向下滚动时脱离，上滚时保持底部支撑。
- 坐标换算在下一次绘制前执行，同时平移物理插值的两个端点；滚动位移不参与物理速度计算，也不重置空中的动作或计时。无需滚动停止计时器、最低抬升高度或额外冲量。
- 挂墙、爬墙或挂顶遇到真实滚动会松手。主页面滚动换算文档位置；内部容器滚动只触发松手，不改变文档位置。拖拽、暂停、恢复和开关切换清理输入；关闭互动或失权期间仍更新采集基线。
- 仅因视口平移越过底部时收回到地面并恢复站立，不播放撞地动画；由宠物自身向下运动触底时，才播放素材包落地动画。
- 自由落体仅在向下运动跨过底部、交点位于有效地面区间时结束，并继续素材包原有落地动画。沿墙垂直滑落不会重新挂墙；向侧墙运动发生实际撞击时恢复抓墙，抛掷向上碰顶可挂顶。明确的跑向墙面、跳墙和爬墙到天花板动作链保留。
- 左右和底部始终有界；仅普通 Fall 下落行为可越过顶部。爬墙、跳跃、抛掷和拖拽四面有界；地面向侧边运动撞墙后开始爬墙；空中撞墙或抛掷碰顶后抓住表面。边界不会单凭坐标贴边而重新吸附松手下落的宠物。无需自动重生。

## 后台成本

失权页面立即停止 rAF 和快照上报并隐藏桌宠，保留实例 30 秒用于复用；超时销毁实例。
后台冻结可能延后销毁定时器，但不会继续模拟。恢复不补算离开期间的时间。

执行者每 500ms 上报完整快照，后台周期写入 `storage.session` 最多每 5 秒一次，执行权变更立即保存。
`storage.session` 仅用于会话内服务工作线程重启恢复；关闭浏览器或重新加载扩展后不保证保留状态。
全局禁用明确清空恢复状态，重新启用时宠物重新出场。

## 验证

`npm run test:relay` 验证文档身份、交接竞争、完整组提交、存储节流、动作寻址、坐标映射、资源释放、滚动基线、脱墙、自由落体、越界和底部穿越碰撞。
`npm run build:all` 同时检查核心与扩展 TypeScript，并生成库、扩展和 ZIP。
