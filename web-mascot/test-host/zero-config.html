未打包宿主（no-bundler）

这个页面 完全不调用 configure()，也不告诉引擎资源在哪： 精灵必须从包自身推导出的地址加载，否则全部 404。

范围说明：这里验证的只是「模块文件被原样服务」这一种环境 —— 裸说明符被别名到 dist/index.js，并由 vite.test-host.config.ts 手工把 dist/mascot_pack 挂在推导出的路径上。它不代表打包器宿主的行为： 经 Vite / Webpack 预构建后，推导值会指向构建产物目录而全部 404，那时必须 configure({ assets })（见 README「30 秒上手」）。
